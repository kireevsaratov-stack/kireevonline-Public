# Проверки в настоящем браузере

Скрипты запускают Chrome без окна и проверяют сайт так, как его видит человек: анимации, загрузку
картинок, перетаскивание в панели, вид на телефоне. Нужны Google Chrome и Node 24 (WebSocket встроен),
других библиотек нет. Временный профиль Chrome — во временной папке системы, профиль Романа не трогается.

Сначала запустить копию сайта на Mac (`http://localhost:8100`, база `../db.sqlite3`, фото из `../../backups/media`),
затем из этой папки: `node <скрипт>`.

| Скрипт | Что проверяет |
|---|---|
| `spin_check.mjs [ширина высота прогонов]` | «Барабан»: старт и остановка барабанов, точность, сборка и проявление сетки |
| `reel_unique_check.mjs [адрес] [пауза мс]` | у каждого барабана свои картинки, без повторов подряд и пересечений |
| `lever_check.mjs` | рычаг «Барабана»: шарик круглый и только опускается |
| `album_check.mjs [адрес] [phone]` | альбом: сначала 40 превью, прокрутка догружает, битых нет, просмотр открывается |
| `manage_e2e.mjs [ширина]` | панель `/admin/`: вход через свою страницу, перетаскивание мышью и пальцем, скрыть, переименовать, создать и удалить, тексты, перенос фото — всё с возвратом как было |
| `upload_check.mjs` | загрузка через страницу панели: временный скрытый альбом с «неудобным» названием, картинка 2600×1800 → в базе, ужата до 1920, превью; при истёкшем входе загрузка останавливается; всё за собой убирает; **сам сообщает «прошло / не прошло»** (код выхода) |
| `keyboard_check.mjs [адрес]` | фото и меню доступны клавишей Tab, Enter открывает фото, Esc закрывает; **сам сообщает «прошло / не прошло»** |
| `nav_check.mjs` | шапка на ширинах 412–1440: переносы, гамбургер |
| `view_shot.mjs адрес ширина высота файл [phone]` | снимок первого экрана |
| `page_shot.mjs адрес ширина файл [phone]` | снимок альбома или «Обо мне» с раскрытыми записками |
| `diag_live.mjs [адрес]` | «Барабан» на ЖИВОМ сайте как телефон: снимки каждые 0,25 с, журнал загрузки картинок (`THROTTLE=1` — медленная сеть) |

`manage_e2e.mjs` входит временным админом ТОЛЬКО в локальной базе: создать пользователя `ui-check` с
случайным паролем (пароль — в файл `kireevonline-ui-check-pw.txt` во временной папке системы), после проверки
пользователя удалить, файл с паролем стереть. Как это сделать — скил `browser-check`.
