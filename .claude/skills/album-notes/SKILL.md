# Записки альбома

Сайт — личный фотодневник. Тон — тёплый, разговорный, без пафоса и красивостей. «Короче» и разговорность —
голос Романа, не вычищать.

## Поля альбома
Панель → «Альбомы» → «тексты» у альбома (`/admin/album/<id>/`, справа живой вид):
- **Место** и **Когда** — строка под названием («Пекин · декабрь 2025 · 155 фото»). В «Когда» — **один месяц**,
  не диапазон (для Путешествий).
- **Коротко** — одна строка под строкой места. Пишет Роман; Claude может предложить вариант.
- **Записки** — впечатления, абзацы через пустую строку, раскрываются по «+».
- **Снято на** — камера + серия/производитель, фокусное, диафрагма: «Canon R6 Mark II + RF 135 1.8 + RF 50 1.2»,
  Sony — «GM 70-200 2.8»; несколько камер — через «;» (каждая своей строкой). Какую технику упоминать, решает Роман.
  Роман иногда путает камеры (A7C II ↔ A7R V) — сверять с оригиналами и говорить ему.

## Порядок
1. **Посмотреть ВСЕ кадры альбома, не выборку** — бывают уникальные, но «местные» кадры.
   Листы: `ALBUM=<id> ../.venv/bin/python manage.py shell < .claude/skills/album-notes/scripts/contact_sheets.py`.
2. **Данные съёмки из оригиналов** в `~/Фото/<событие>/` — только дата, камера, объектив (разрешение Романа
   01.10.2026; координаты не читать): `scripts/match_originals.py` с `ALBUM=<id>`.
3. **Вопросы Роману** по поездке (20–50, по кадрам, с номерами кадров), записать их в
   `~/Claude Code/kireevonline/notes/albums/<альбом>.md` (вне git — там личное) сразу, а не только в чат.
   Туда же — ответы.
4. **Текст.**
   - Пишет Роман сам → Claude правит только опечатки и пунктуацию; всё сверх — нумерованными предложениями
     «было → стало», применять только одобренные номера.
   - Пишет Claude по ответам → только факты Романа, его словами; в своих фразах — без негатива.
     Роман потом переписывает сам — его текст становится каноном.
5. **На сайт** текст вставляет Роман через «тексты» в панели — выкладка не нужна. Готовый текст отдать одним
   блоком, абзацы через пустую строку. После — проверить страницу альбома как посетитель.
6. Локальная база после правок на сайте отстаёт — обновить: `python3 deploy/backup.py --db-only` и скопировать
   свежий файл из `../backups/db/` в `gallery/db.sqlite3` (старую — в `../_архив/`).
